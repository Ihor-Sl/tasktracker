# TaskTracker

Легкий консольний менеджер задач на Python, створений у межах лабораторної роботи
з дисципліни «Системи керування версіями».

## Встановлення

1. Клонувати репозиторій.
2. Запустити `python app.py`.

## Функції

- Додавання задач
- Видалення задач
- Реєстрація користувачів
- Позначення задач виконаними
